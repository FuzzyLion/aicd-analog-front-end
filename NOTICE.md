# Attribution and scope

This repository presents student work from the Advanced Integrated Circuit Design Lab at TU Darmstadt, summer semester 2026. It is a personal portfolio edition of a group project. It does not imply university endorsement.

The roles of Qi Wu and the project teammate are described in [contributions.md](docs/contributions.md). The teammate's layout images and physical-verification screenshots are excluded. Course context and specifications are identified in the report; the original handouts, university logos, course report template, and private preparation material are not redistributed here.

The PDF was rebuilt from the integrated report with a standard LaTeX report class. Student numbers, the teammate's name and the administrative course cover were removed. Contribution wording was aligned with the detailed task split. The controller is described as behavioral without asserting a separately documented course approval. The schematic result values were preserved. Teammate layout images, physical-verification screenshots, and the full device operating-point CSV are excluded from this edition.

The repository contains no foundry PDK model files, extraction decks, native Cadence library database, or complete replayable PGA netlist. Screenshots and exported results document the available lab work. Third-party tool, institution, and technology names belong to their respective owners.
